# 쪽지 — 영원 → 서정·미리

## 무엇을 건드렸나

내 담당 폴더(`screen/`) 밖인 아래 5개 파일을 만들었다.

- `mission/missions.json`
- `mission/mission-engine.js`
- `guide/ai-guide.js`
- `guide/voice.js`
- `shared/CONTRACT.md`

## 왜 고쳤나

A(화면) 작업을 끝내고 확인해 보니 버튼을 눌러도 화면이 안 넘어갔다. 원인은 `plan.md`가 S0에서 "셋이 같이" 만들기로 정해둔 계약·스텁이 아직 없어서였다 (`missions.json`, `mission-engine.js`, `ai-guide.js`, `voice.js`, `CONTRACT.md`). 셋이 모이는 자리가 없어서 내가 대신 `plan.md`에 이미 합의된 내용을 **그대로 옮겨 적었다.** 새로 만든 로직은 없다.

- `mission-engine.js`: 뭘 눌러도 다음 단계로 넘어가는 스텁 (정답 판정 없음)
- `ai-guide.js`: 고정 문구를 돌려주는 스텁 + 도움바 최소 배선
- `voice.js`: 항상 미지원으로 답하는 스텁
- `missions.json`, `CONTRACT.md`: `plan.md` S0에 적힌 값 그대로

## 되돌리는 법 (통째로 교체해도 된다)

이 파일들은 **너희가 실제 로직으로 통째로 갈아엎는 걸 전제로 만든 스텁**이다. 내용이 마음에 안 들면 그냥 지우고 다시 써도 된다 — 함수 이름(`getStep`/`submit`/`getMission`/`askAI` 등)과 `data-action` 값만 `shared/CONTRACT.md` 와 맞으면 된다.
