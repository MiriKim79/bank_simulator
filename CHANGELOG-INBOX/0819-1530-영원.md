안 건드렸다. `guide/` 는 그대로 두고, 크롬으로 재검증하다 발견한 문제만 남긴다.

## 왜 남기나

`b8a511f`(F6 단일 출처 고침)는 잘 됐다. 근데 그 김에 `qa-data.json`의 계좌/은행/금액 키워드 답변이 값을 빼고 **"화면에 안내된 OO를 그대로 입력하세요"** 식으로 바뀌었는데, 실제로는 **그 화면에 계좌번호·금액이 안 보인다.**

크롬에서 재현:
1. 이체 → 한걸음은행 선택 → 계좌번호 입력 화면 진입
2. 화면엔 "수취인: 김민수 (한걸음은행)"만 있고 계좌번호는 어디에도 안 뜬다
3. "물어보기" 눌러 "계좌번호가 뭐예요" 질문
4. 답: **"화면에 안내된 계좌번호를 그대로 입력하세요."** ← 안내된 게 없어서 헛답

원인: `matchLocal`이 키워드부터 먼저 보고(`matchKeywords`), 맞으면 그 답을 바로 쓴다. `fromMission()`(진짜 번호를 아는 폴백)은 **키워드가 하나도 안 맞을 때만** 돈다. "계좌"·"번호"·"얼마"·"금액" 같은, 사용자가 제일 많이 쓸 단어들이 이미 `qa-data.json`에 키워드로 박혀 있어서 정작 그 질문을 하면 `fromMission`까지 안 간다.

F13/F14는 "막혔을 때 답 받기"가 목적인데, 계좌번호·금액을 직접 물어보는 제일 흔한 경우에 안 먹힌다. F6은 고쳤지만 F13 기능이 새로 깨진 셈이라 표시해 둔다.

## 제안 (하나만 고르면 됨)

- (A) `qa-data.json`에서 값 있는 키워드 항목(계좌·번호·얼마·금액·은행·이름·골라·선택) 자체를 지운다 → 항상 `fromMission()`으로 감
- (B) 순서를 뒤집는다: `fromMission(step, mission)`을 먼저 보고, 값 있으면 그걸 쓰고, 없을 때만 `matchKeywords`

(A)가 더 적은 코드. 둘 다 급한 건 아니고 Should 여유 있을 때 반영하면 됨.
