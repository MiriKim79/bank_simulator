# 쪽지 — 영원 → 미리

## 무엇을 건드렸나

`screen/` 안쪽(내 담당) 외에, **`shared/CONTRACT.md`·루트 `OWNERS.md`도 직접 고쳤다.** 원래 이 둘은 통합자(미리)만 고치는/세 사람이 같이 고치는 파일인데, 사용자(팀 대표 권한)가 "갱신도 네가 해"라고 명시적으로 지시해서 예외로 직접 반영했다. 임의 판단 아니고 사람 지시다.

- `shared/CONTRACT.md`: 1절 "화면 이름 7개" → "8개"로, `intro` 화면 추가(quiz와 같은 방식, 미션 아님) / 3절 DOM id 목록에 `#screen-intro` 추가
- `OWNERS.md`: 「공통 약속」 표의 "화면 이름 7개" 줄, `screen/` 행의 "화면 7개 DOM" 문구 — 둘 다 8개로 갱신

## 왜 고쳤나

팀 UI 피드백(고령자 UX 강화 — 미션 안내를 첫 화면에만 보여주고, 실제 연습 중엔 정답을 계속 노출하지 않기)을 반영하면서 `screen-intro` 화면을 하나 새로 추가했다. `quiz`와 같은 방식 — `missions.json`에 없는, 순수 화면 전환용(미션 판정과 무관, `data-goto` 속성으로 `BankUI.showStep()`만 호출하고 `MissionEngine`은 안 부른다).

그 외 변경: 상단 고정 헤더(앱 이름·부제·안전 안내) 추가, AI 도움 버튼을 "💬 AI 선생님에게 물어보기" 하나로 통합하고 클릭 시 패널 열림, 오답/AI답변/완료 색상 분리(빨강/파랑/초록), 금액 입력 천 단위 쉼표. **DOM id·`data-action`·`BankUI`/`MissionEngine`/`AIGuide` 시그니처는 안 건드렸다** — `#help-ask`·`#help-repeat`·`#question-box` 등 id 그대로, 위치만 재배치.

## 되돌리는 법

`screen/bank-ui.html`·`screen/styles.css`·`shared/CONTRACT.md`·`OWNERS.md` 네 파일 다 이 커밋 이전으로 되돌리면 된다. `mission/`·`guide/`는 손 안 댐.

## 확인했으면

내용 확인만 하면 됨(이미 반영 끝). `SYNC-LOG.md` 비고 칸에 한 줄 남기고 이 쪽지 지워도 된다.
