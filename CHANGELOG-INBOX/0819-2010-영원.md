# 쪽지 — 영원 → 미리

## 무엇을 건드렸나

`guide/qa-data.json` 직접 고쳤다. 원래 `guide/`는 미리(C) 담당인데, 사용자(팀 대표 권한)가 "아직 안고친걸 내가 고쳐"라고 명시적으로 지시해서 예외로 직접 반영했다.

- `byStep.account.items`에서 `{"keywords": ["계좌","번호","입력","값"], "answer": "화면에 안내된 계좌번호를 그대로 입력하세요."}` 항목 삭제
- `byStep.amount.items`에서 `{"keywords": ["얼마","금액","값"], "answer": "화면에 안내된 금액을 그대로 입력하세요."}` 항목 삭제

## 왜 고쳤나

`0819-1530-영원.md`에서 리포트했던 회귀가 그대로 남아 있었다: `ai-guide.js`의 `matchKeywords`가 `fromMission` 폴백보다 먼저 실행되는데, 지운 두 항목의 키워드("계좌"/"번호", "얼마"/"금액")가 너무 넓어서 "계좌번호가 뭐예요"/"얼마예요" 같은 가장 흔한 질문을 가로채 실제 값 없는 답변만 반복했다. `missions.json`의 `wrong` 문구엔 실제 계좌번호(11022233344)·금액(50000)이 있는데 거기까지 못 갔다.

항목을 지우면 `matchKeywords`가 null을 반환하고 `fromMission`이 실제 값이 든 답변을 준다. 다른 키워드(하이픈, 수취인, 0 개수)는 그대로 둬서 그쪽 답변은 안 바뀐다. 브라우저로 재확인 완료 — "계좌번호가 뭐예요" 질문에 실제 번호 포함된 답변 나옴.

`ai-guide.js` 코드(우선순위 로직) 자체는 안 건드렸다. `qa-data.json` 데이터만 고쳤다.

## 되돌리는 법

이 커밋 이전으로 `guide/qa-data.json`만 되돌리면 된다. 지운 두 항목을 원래 자리(각 배열의 첫 번째)에 다시 넣으면 원상복구.
