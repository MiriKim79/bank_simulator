# 쪽지 — 영원 → 미리(통합자) · 서정(B)

## 무엇을 건드렸나

`screen/` 안쪽(내 담당)만 고쳤다. 남의 폴더 파일은 만들지도 고치지도 않았다.

- `screen/bank-ui.html`
  - `#screen-intro` 에 진입 버튼 추가: `<button data-goto="glossary">📖 금융 용어 퀴즈</button>`
  - **화면 1개 신규**: `#screen-glossary` — "쉬운 금융 용어 사전". 5묶음 · 용어 20개를 `<details>` 로 접어 둔다
  - 사전 맨 아래 버튼 2개: `#glossary-to-quiz`(O·X 퀴즈로) / `data-goto="intro"`(처음 화면으로)
  - 인라인 `BankUI` 의 `SCREENS` 배열에 `'glossary'` 추가 (8개 → 9개)
  - `#glossary-to-quiz` 클릭 배선: `window.Quiz.start()` 가 있으면 `showStep('quiz')` 후 호출, 없으면 `BankUI.showAnswer()` 로 "준비 중" 안내
- `screen/styles.css` — 맨 아래 `.glossary-group` / `.term` / `#glossary-to-quiz` 블록 추가. 색은 기존 `:root` 토큰만 사용(새 토큰 없음), 애니메이션 없음

브랜치: `feature/finquiz-lingo`

## 왜 고쳤나

사용자(팀 대표 권한) 지시로, 첫 화면에서 바로 들어가는 **용어 사전**을 만들고 그 아래에서 O·X 퀴즈로 넘어가게 했다.
사전 내용(어르신 눈높이 설명 + 쉬운 비유)은 사용자가 그대로 준 원고다.

## 확인·결정이 필요한 것 3가지 (임의로 확정하지 않았다)

1. **화면 이름이 9개가 된다.** 「공통 약속」의 "화면 이름 8개"(`OWNERS.md` · `shared/CONTRACT.md`)와 어긋난다.
   `glossary` 는 `intro`·`quiz` 와 같은 부류다 — `missions.json` 에 없고 `MissionEngine` 을 부르지 않는 순수 화면 전환.
   두 문서 갱신은 통합자(미리) 몫이라 내가 고치지 않았다.
2. **`SPEC.md` 에 없는 기능이다.** F16(금융용어 미니 퀴즈)은 있지만 "용어 사전"은 없다.
   또 F16 상세는 **객관식 3~5문제**인데 이번 진입 버튼은 **O·X** 로 적혀 있다. `SPEC.md` 12절에 결정 항목으로 올릴지 통합자가 판단해 달라.
3. **O·X 퀴즈 본체는 안 만들었다.** `#screen-quiz` 안쪽과 `mission/quiz.js` 는 B(서정) 소유라 손대지 않았다.
   지금은 `mission/quiz.js` 가 없어서 버튼을 눌러도 "아직 준비 중" 안내만 나온다. `Quiz.start()` 만 생기면 그대로 연결된다.
   B가 완료 화면의 `#quiz-start` 처럼 이 버튼도 잡고 싶다면 id 는 `#glossary-to-quiz` 다.

## 참고 — 원고에서 바꾼 부분

사용자 원고에 실존 은행명(신한·KB·하나·농협·국민·우체국)이 있었는데, 루트 `CLAUDE.md` 의 "실제 은행 브랜드 복제 금지" 규칙에 걸려
"내가 자주 쓰는 은행" / "은행 앱 하나만 켜면" 으로 일반화해서 넣었다. 되돌릴지 여부는 팀이 정하면 된다.
