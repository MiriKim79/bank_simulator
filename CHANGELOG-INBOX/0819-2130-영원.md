# 쪽지 — 영원 → 미리·서정

## 무엇을 건드렸나

팀이 준 "금융한걸음 — 최종 UI 제안" 이미지 시안을 반영했다. 사용자(팀 대표 권한)가 "이렇게 해고 SPEC을 수정해"라고 명시적으로 지시해서, 평소엔 안 건드리는 `SPEC.md`·`shared/CONTRACT.md`도 이번엔 직접 고쳤다.

- `screen/bank-ui.html`·`screen/styles.css`(내 담당): 잔액조회 버튼 제거, 은행/계좌/금액 화면 수취인 힌트 제거, 진행 표시 `n/5`→`n/4`(완료 화면 제외)로 변경 + 알약 배지 스타일, 인트로 화면에만 앱 이름·부제 노출, "← 처음으로" 링크 추가(`data-goto="home"`), 인트로 화면에 `#quiz-start-intro` 버튼 추가(hidden)
- `SPEC.md`(원래 통합자만): 6.1·F17 표·13.3 S3 텍스트를 `n/4`로 갱신, 13.6절 신설 — 이번 시안을 13.3과 같은 방식(반영/단순화/제외/Must 보호로 보류)으로 분류
- `shared/CONTRACT.md`(원래 통합자만): 3절 DOM 목록에 `#quiz-start-intro` 추가

## 왜 고쳤나

시안을 다 따르면 Must 두 개가 깨진다 — 계좌/금액 화면 키패드 제거(F5 후퇴), AI 도움 진입점을 홈에만 두기(F14 "어느 화면에서나" 위반). 이 둘은 SPEC.md 13.6 "Must 보호로 보류" 표에 사유와 함께 남기고 **코드는 그대로**(키패드·모든 화면 AI 진입점 유지)뒀다. 나머지(잔액조회 제거, 진행 표시 분모, 힌트 문구 제거, 뒤로가기 등)는 반영했다.

**서정 확인 필요한 것**: `#quiz-start-intro` — `mission/quiz.js`(F16, 아직 없음) 만들 때 완료 화면의 `#quiz-start`와 같이 이 버튼도 노출·배선해줘야 한다. `missions.json`은 안 건드렸다(진행 표시 분모 변경은 화면 쪽 계산으로만 처리했다 — SPEC 13.3 S3 갱신 참고).

**계좌 별명("생활비 통장")·완료 화면 퀴즈 재방문 버튼**은 스키마 변경·F16 구현이 먼저라 SPEC 13.6에 "팀 결정 필요"로만 남기고 반영 안 했다.

## 되돌리는 법

`screen/bank-ui.html`·`screen/styles.css`·`SPEC.md`·`shared/CONTRACT.md` 네 파일을 이 커밋 이전으로 되돌리면 된다. `mission/`·`guide/`는 손 안 댐.

브라우저로 완주(1~4단계+완료)·오답(거래내역) 재검증 끝. 내용 확인만 하면 됨. `SYNC-LOG.md` 비고 칸에 한 줄 남기고 이 쪽지 지워도 된다.
