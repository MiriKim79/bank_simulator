# 쪽지 — 서정(B) → 미리(통합자) · 영원(A)

## 무엇을 만들었나

`mission/` 안쪽(내 담당)만 새로 만들었다. 남의 폴더는 손대지 않았다.

- `mission/quiz-data.json` — O·X 문항 **10개** (`{ id, text, answer, explain }`)
- `mission/quiz.js` — `window.Quiz`. `#screen-quiz` 안을 직접 그린다
  - 한 화면에 **한 문제**만 보여 준다
  - 답하면 **문제 위 카드**에 `정답: O/X` + 해설이 크게 뜬다 (정답 초록 · 오답 빨강)
  - 답한 뒤 버튼 2개: `다음 문제 풀기`(마지막 문제에서는 `결과 보기`) · `처음 화면으로`
  - 마지막까지 풀면 마무리 카드 + `처음 화면으로` · `다시 풀기`
  - 오답이어도 다시 고를 기회를 주지 않는다 (`SPEC.md` 12.2 확정값)
  - `quiz-data.json` 로딩에 성공했을 때만 완료 화면의 `#quiz-start` 를 보여 주고 클릭을 배선한다

브랜치: `feature/finquiz-lingo`

## 확인·결정이 필요한 것 (임의로 확정하지 않았다)

1. **`SPEC.md` 4.1 F16 과 다르다.** SPEC 은 「객관식 3~5문제」인데 사용자가 준 원고가 **O·X 10문제**라 그대로 만들었다.
   `mission/CLAUDE.md` 의 "문항 5개" 문구와도 어긋난다. 문서를 어느 쪽으로 맞출지 통합자가 정해 달라.
2. **용어 출처도 다르다.** SPEC 은 「송금 6단계에서 실제 화면에 등장한 용어만」인데, 문항이 인증서·OTP·스미싱·지연이체까지 다룬다.
   용어 사전(`#screen-glossary`) 내용을 복습하는 퀴즈라 사전 기준으로는 맞다.
3. **끝내고 돌아가는 화면은 항상 `intro`(처음 화면)다.** 버튼 문구가 `처음 화면으로` 라서 어디서 들어왔든 같은 곳으로 나간다.
   `SPEC.md` 4.1 F16 의 「끝나면 완료 화면으로 복귀」와는 다르다 — 완료 화면 말고 용어 사전에서도 들어올 수 있게 되면서 바뀐 부분이다.
4. **스타일을 `quiz.js` 안에서 넣었다.** `screen/styles.css` 는 A 소유라 열지 않고, `#screen-quiz` 안쪽만 겨냥한 `<style>` 을 스크립트가 주입한다.
   색은 A의 `:root` 토큰(`--info-bg`·`--success-bg`·`--error-bg`·`--accent`)만 써서 다크모드도 따라간다. A가 `styles.css` 로 옮기고 싶으면 그대로 가져가면 된다.
5. Q10 원고에 실존 은행명(신한·국민·농협)이 있었는데, 루트 `CLAUDE.md` 의 브랜드 복제 금지 규칙 때문에 "은행 앱 하나에서 다른 은행 통장"으로 일반화했다.

## 되돌리는 법

`mission/quiz.js` · `mission/quiz-data.json` 두 파일을 지우면 된다. `bank-ui.html` 은 원래 `quiz.js` 가 없으면 404 만 찍고 그대로 도는 구조다.
