# 금융한걸음

고령자를 위한 AI 모바일뱅킹 학습 서비스

## 실행 방법

빌드·번들러·프레임워크 없는 바닐라 HTML/CSS/JS. 별도 패키지 설치가 필요 없다.

### 필요한 것

- **Python 3** (표준 `http.server` 모듈만 쓴다 — 이 저장소는 3.14.7로 확인했지만 3.x면 다 된다)
- 브라우저 아무거나 (마이크 질문(F12)까지 쓰려면 Chrome — `webkitSpeechRecognition` 필요. 다른 브라우저는 마이크 버튼만 안 보이고 나머지는 그대로 동작)

### 설치

설치할 게 없다. 저장소를 받기만 하면 된다.

```bash
git clone https://github.com/MiriKim79/bank_simulator.git
cd bank_simulator
```

### 실행

```bash
python3 -m http.server 8000
```

띄운 채로 브라우저에서 아래 주소를 연다.

```
http://localhost:8000/screen/bank-ui.html
```

**`file://`로 직접 열면 동작하지 않는다.** 페이지가 `fetch`로 JSON 데이터를 읽으니 반드시 위처럼 HTTP 서버를 거쳐야 한다.

### 확인 방법

테스트 러너가 없어서, 아래 3단계를 같은 절차로 쓴다 (`OWNERS.md` 「검증 명령」과 동일):

1. 홈 화면에서 이체 → 한걸음은행 → `11022233344` → `50000` → 보내기 → 완료 화면까지 간다
2. 홈에서 "거래내역"을 누르면 화면이 넘어가지 않고 오답 설명이 뜬다
3. "다시 설명해주세요"를 누르면 답변이 화면에 뜬다 (소리는 나지 않는다)

세 개 중 하나라도 안 되면 브라우저 콘솔(개발자 도구)에 에러가 있는지부터 본다.

자세한 기획은 `SPEC.md`, 팀 작업 규칙은 `CLAUDE.md`, 진행 상황은 `tasks.md`를 본다.
