# 기존 서비스 조사

## 신한 SOL뱅크 체험 서비스

SPEC.md 13절 기준으로 8화면을 브라우저에서 직접 확인했다(2026-08-19). 자세한 화면별 내용은 `ui-reference.md` 참고.

### 확인한 기능

- **신한 SOL뱅크 공식 체험 서비스는 이미 실제 돈 없이 모바일뱅킹 송금을 따라 해보는 기능을 제공한다** (쉬운 홈 → 받는통장 입력 → 금액 입력 → 확인 → 이체완료 → 거래내역조회, 8화면 전체가 "따라하기 체험화면으로 실제 이체가 되지 않아요"로 안내됨).
- 화면 진행 표시(`1/3`~`3/3`), 도움 진입점(챗봇·음성 아이콘), 완료 후 "한번 더 따라하기" 등 학습 편의 요소도 이미 갖추고 있다.
- **다만 이 체험에는 오답·예외 화면이 존재하지 않는다.** 캐릭터 말풍선과 빨간 점(`Click Here`)이 다음에 누를 곳을 직접 지시하는 방식이라, 사용자가 정해진 경로만 따라가면 틀릴 수가 없는 구조다(SPEC 13.4).

### 참고할 UX

- ui-reference.md의 "반영"·"단순화" 항목 참고 (홈 진입, 진행 표시, 큰 금액 강조, 도움 진입점 배치, 화면 분리 방식 등).

### 그대로 복제하지 않을 요소

- 로고·브랜드명·고유 색상·이미지·아이콘 (SPEC 13.1). 화면은 가상 은행으로 만든다.
- Click Here 방식의 정답 위치 직접 지시 — 이 서비스는 사용자가 스스로 찾아 누르는 것을 학습 목표로 삼으므로 넣지 않는다(SPEC 13.3 X8, F10 Won't).

## 차별점 정리

**주의**: "고령자를 위한 모바일뱅킹 시뮬레이터" 자체는 차별점이 아니다. **신한 SOL뱅크 공식 체험 서비스가 이미 실제 돈 없이 모바일뱅킹을 따라 해보는 기능을 제공하고 있음이 확인됐다** (위 "확인한 기능" 참고). 따라서 이 문구만으로 차별점을 주장하지 않는다.

### 기존 서비스 (신한 SOL뱅크 체험)

- 실제 돈 없이 송금 흐름을 따라 해보는 기능 제공
- 진행 표시, 도움 진입점(챗봇·음성), 완료 후 재시도 등 학습 편의 요소도 이미 갖춤
- **캐릭터가 빨간 점으로 다음 누를 곳을 직접 지시** — 정해진 경로만 따라가므로 오답·예외 화면이 없다(SPEC 13.4)
- 스마트투게더: `[실사용 확인 필요]` — 아직 조사 전

### 금융한걸음

우리의 차별점은 **사용자의 현재 질문 + 현재 단계 + 현재 미션을 함께 이해하고, 그 상황에 맞춰 설명하는 AI 학습 도우미**다.

- SPEC F13(askAI)·F14(도움 진입점)이 이 차별점의 구현체다. `askAI(question, currentStep, mission)`이 질문뿐 아니라 현재 단계와 미션 데이터를 함께 받아 답변 근거로 쓴다(SPEC 8장).
- "시뮬레이터"라는 형태 자체가 아니라, AI가 지금 사용자가 어느 단계에서 무엇을 묻는지 함께 이해하고 그에 맞춰 설명한다는 점이 핵심이다.
- **오답 피드백(F8)도 핵심 차이를 만든다.** SOL 체험은 정해진 위치를 안내해 사용자가 사실상 틀리지 않도록 하는 반면(위 "확인한 기능" 참고), 금융한걸음은 사용자가 직접 행동하고 틀렸을 때 이유를 설명하며 스스로 회복하게 한다(SPEC 6.1 기준 4, SPEC 13.4). SOL에는 이 부분을 베낄 실제 화면이 없으므로, 이 서비스가 직접 설계해야 하는 지점이자 SOL과 구별되는 지점이다.
- 스마트투게더와 겹치는지는 실사용 확인 후 재검증한다.
