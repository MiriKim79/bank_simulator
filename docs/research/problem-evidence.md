# 문제 근거 조사

## 핵심 문제 정의

`SPEC.md` 3장(문제)에 정리된 내용을 그대로 옮긴다.

1. 은행 업무가 모바일 중심으로 이동하는 중인데, 고령자는 진입에서 막힌다.
2. 연습할 방법이 없다. 실제 뱅킹 앱은 잘못 누르면 실제 돈이 움직이므로, "일단 해보면서 익히기"라는 학습 방식이 봉쇄돼 있다.
3. 옆에서 알려줄 사람이 항상 있지 않다. 한 번 배워도 혼자 다시 하려 하면 기억이 나지 않는다.

→ 실수해도 안전한 환경에서, 옆에서 알려주는 사람 역할을 AI가 대신하며 반복 연습할 수 있게 한다.

## 프로젝트에 반영할 핵심 인사이트

- SPEC 8장 D2에 따라, askAI는 LLM 우선 → 실패 시 미리 쓴 답변 폴백 구조를 갖는다. 이는 "발표 중 네트워크 사고로 데모가 죽지 않아야 한다"는 6.1절 성공 기준 3과 직결된다.
- SPEC 5.2에 따라 iOS Safari(및 iOS Chrome)는 Web Speech API 음성 인식을 지원하지 않는다. 시연 환경이 iOS 기기라면 Must 기능(F12)이 동작하지 않으므로, 시연 환경 확정(SPEC 5.3 `[확인 필요]` Q6) 전까지는 데스크톱 Chrome 또는 Android Chrome을 전제로 개발해야 한다.
- SPEC 3장의 핵심 문제(연습 수단 부재)가 실제 통계로도 뒷받침되는지는 위 세 기관 자료의 원문 확인 후에만 발표 자료에 수치로 인용한다.
